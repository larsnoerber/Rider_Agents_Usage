# AgentMeter

## Short description (manifest)

Track AI usage quotas in a movable browser bar, with reset countdowns and configurable quota warnings.

## Store description

Keep your AI usage quotas in view while you browse. AgentMeter displays provider-reported allowances in a compact,
movable bar and provides quota details through its browser toolbar popup.

Choose OpenAI Codex, Claude, Cursor, GitHub or Gemini Apps once in Settings. Selected providers appear together in
the bar and refresh in the background after you grant website access. Click a provider to open its website, or
expand the details to see the reported quota categories and reset countdowns.

Features:

- Movable, collapsible page bar with a remembered position.
- OpenAI session and weekly remaining quotas; Gemini session and weekly consumption.
- GitHub included-credit and inline-suggestion consumption when reported.
- Per-provider last-update times and clearly labelled saved values.
- Configurable quota-warning colors, refresh interval, theme and popup layout.
- Automatic saving for all settings.

Sign in on the providers' official websites first. AgentMeter uses those browser sessions only to read that
provider's quota. It does not request passwords or API keys, collect conversations, run remote code, or send data
to an AgentMeter server. Quota values and settings are stored locally.

Provider access is optional. Showing the bar on other websites requires an additional optional website permission;
the bar does not read their content. Protected browser pages cannot show the bar.

Available quotas depend on your subscription and provider interface. Claude Free may not report quota percentages.
Missing values show dashes, never estimated allowances. Private provider interfaces can change or reject reads.
The browser must remain running for background updates.

AgentMeter is an independent project and is not affiliated with the listed providers.

## Additional privacy wording for the description

AgentMeter checks open-tab URLs locally to locate provider tabs. It does not save or export browsing history.
