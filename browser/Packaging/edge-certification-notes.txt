AgentMeter displays provider-reported AI quotas. It has no separate AgentMeter account. The UI is English.

Testing requires an account with a supported provider. Shared credentials are not supplied because provider
accounts may be tied to personal subscriptions, organization access and multi-factor authentication. Please use
reviewer-controlled accounts. Some quotas require a paid subscription. Further account evidence can be requested.

Test steps:
1. Install the extension and open Settings.
2. Select OpenAI Codex, Claude, Cursor, GitHub or Gemini Apps.
3. Grant individual provider access, or use Allow website access & show bar everywhere.
4. Sign in on the selected provider's official website.
5. Open the popup and select Refresh; compare with the provider's own usage page.
6. With all-site access enabled, open an ordinary HTTPS page to see the bar.
7. Drag the move handle or use arrow keys. The position is saved. Expand details for reset countdowns.
8. Change provider selection, theme or warning threshold. Settings save automatically.
9. Deselect providers to stop their reads. Clear saved usage after switching accounts.

OpenAI and Claude show remaining quota; GitHub, Cursor and Gemini show consumption. Values depend on the account
and provider. Claude Free may report no percentages. Multiple Claude organizations can require selecting one
on the website and keeping its tab open. Missing values are dashes. Cached observations retain their timestamps.

Polling requires a running browser and valid sessions. Reads are throttled to at least one minute; HTTP 429 pauses
retries for 15 minutes. Protected browser pages cannot show the bar. All-site access displays the overlay without
reading unrelated content. All code is packaged. There is no telemetry or AgentMeter server.
Store screenshots use labelled demo data, not authenticated account evidence.
